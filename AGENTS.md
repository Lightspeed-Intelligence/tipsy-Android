# Tipsy Android Agent Instructions

Before investigating or changing source code, read `llmdoc/index.md` and the
task-relevant documents it routes to. The cross-platform alignment and
root-cause rules in `llmdoc/index.md` under `## 硬性纪律` apply to every
diagnosis, design, review, and implementation in this repository.

directory-specific rules supplement, rather than replace, the Android shell's
cross-shell and shared-Surface constraints.
